### ✨ What's Inside

| Feature | Detail |
|:--|:--|
| 🔮 **Neon Green Theme** | Head‑to‑toe green — PS1, ls, bat, fzf, everything |
| 💡 **Auto‑Suggestions** | Fish‑like inline suggestions as you type |
| 🎨 **Syntax Highlighting** | Commands, arguments, and paths — all color‑coded |
| 📂 **lsd** | Modern `ls` with icons, tree view, and color |
| 📄 **bat** | `cat` with syntax highlighting and line numbers |
| ⚡ **One‑Line Install** | Single curl command, zero hassle |
